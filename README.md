# AlbionHelper

> 📦 **Project Status: Archived / Completed**  
> *Designed and written on September 7, 2021 (pre-AI era). 100% hand-written code, created without the assistance of ChatGPT or modern LLMs.*

A lightweight external bot for **Albion Online** designed to automate routine farming tasks, featuring a custom licensing system. Built entirely in C#.

---

###  Features

- **Automated Farming:** Handles harvesting, planting, and watering (with focus point management).
- **Unlimited Islands:** Capable of cycling through and managing any number of player islands.
- **External & Non-Invasive:** Relies purely on screen/pixel detection and simulated input (macros). Does not inject into memory, hook the client, or intercept game packets.
- **Human-like Delays:** Includes basic anti-detection mechanisms, such as randomized action timers.
- **Licensing System:** Built-in custom license key verification.
